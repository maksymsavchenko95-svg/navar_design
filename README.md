# Navar Design Prototype

Interactive pitch prototype for [Navar](https://github.com/maksymsavchenko95-svg/navar_siplo) —
a phone-frame mockup of the five-screen flow (goal → numbers → tastes → plan → cart) plus a
scroll-driven landing page. Built with Vite + React 19 + Tailwind v4 in Google AI Studio /
Gemini. Ukrainian copy throughout.

This is a **visual reference**, not the real product — all data in `src/mockData.ts` is
mocked; nothing here talks to Silpo or a backend.

## Run it

```bash
npm install
npm run dev
```
